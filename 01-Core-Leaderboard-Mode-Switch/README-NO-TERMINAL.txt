MAZE ARSENAL — CITY FIX (NO TERMINAL)

What this changes — CITY ONLY:
• Stronger gray City fog.
• The empty area around short City buildings is asphalt like the City floor.
• The City player gets the same active-power-up colored circle used by the normal player renderer.
• Escaping the City records completion so the next numbered level unlocks.
• Other level visuals are not changed.

HOW TO APPLY ON MAC — NO TERMINAL:
1. Unzip this folder.
2. Double-click APPLY_CITY_FIX.applescript.
3. It should open in Apple's Script Editor.
4. Click the ▶ Run button.
5. Choose your local maze-arsenal project folder.
6. When the success message appears, close Script Editor.

The installer creates backups automatically:
src/App.jsx.backup-before-city-fix
src/game/rendering-enhanced.js.backup-before-city-fix

If macOS asks for permission to access the folder, choose Allow.

IMPORTANT:
This installer was made for the current main branch of:
https://github.com/Museappfashion/maze-arsenal

If the expected code has changed, the installer stops instead of guessing.
