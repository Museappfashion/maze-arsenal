MIST MAZE — SKIN PERKS AND SPACE UPDATE — OCTOBER 21, 2026

INSTALL INTO YOUR EXISTING GAME
1. Unzip this download.
2. Open your game folder containing package.json (for example total/).
3. Copy src/ into that folder, merging folders and replacing matching files.
   The main file belongs at total/src/App.jsx, not total/src/src/App.jsx.
4. Copy the included scripts/ and root configuration files into the same project.
5. Keep the existing .env files, api/ folder, and supabase/ folder.
6. Run npm install, npm run verify, and npm run dev.
   Use your usual deployment process to publish when ready.

This is the complete current frontend source, including the earlier October
updates. It includes the new perk and scene modules needed by the game.

NEW EQUIPPED-SKIN PERKS
Turkey — Lucky Peck: ammo pickups give 10% more ammo.
Alien — Alien Recovery: medkits restore 10% more health.
Shadow Wisp — Slip Away: taking damage gives +15% speed for 2 seconds,
  with a 20-second recharge.
Ember Spirit — Ember Strike: every tenth successful weapon hit deals
  3 extra fire damage.
Crystal Guardian — Crystal Shell: absorb up to 5 damage from one hit,
  with a 25-second recharge.

Only the equipped skin grants its perk. Perks work in all four combat mazes.
They use run time and reset on a new run. Hats remain visual. Health/ammo
caps remain in effect. Labyrinth and Free the Flock use their existing rules.
Store cards describe every perk; the game shows the perk's status.
