MAZE ARSENAL — VERCEL HOTFIX V3

This fixes the repeated Vite/Rolldown transform failure where the comment marker
was stripped before the hardening plugin ran again.

The plugin now recognizes already-transformed source using semantic markers:
- leaderboard.js: beginGlobalLeaderboardRun + finishGlobalLeaderboardRun
- world.js: leaderboardEligible
- App.jsx: ModeSwitchWarning + RunEndOverlay + beginLeaderboardRunForWorld
- LevelSelectScreen.jsx: Personal best text

INSTALL:
1. Switch GitHub Desktop to the branch you are deploying (main or pv).
2. Unzip this ZIP.
3. In Finder, open your repo's tools/ folder.
4. Replace:
     tools/mazeHardeningPlugin.js
   with the file from this ZIP.
5. Commit the one changed file.
6. Push.
7. Let Vercel build the new commit.

LOCAL TEST FIRST:
  npm run build

If it succeeds, you should see:
  ✓ built in ...

No Supabase SQL change is required for this build-only hotfix.
