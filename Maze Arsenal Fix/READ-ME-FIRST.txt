MAZE ARSENAL — FINDER INSTALL

1. Unzip Maze-Arsenal-Finder-Fix.zip.
2. Open your maze-arsenal repository in Finder.
3. Drag the entire "Maze Arsenal Fix" folder into the repository root.
   It should sit next to:
     package.json
     src/
     api/
     supabase/
4. Open "Maze Arsenal Fix".
5. Double-click APPLY_MAZE_FIX.command.
6. After it says "Patch applied":
   - Enable Supabase Authentication > Anonymous Sign-Ins.
   - Run the UPDATED supabase/setup.sql in Supabase SQL Editor.
   - Run npm install and npm run check before deploying.
7. Delete the "Maze Arsenal Fix" folder before committing.

The patch includes:
- working anonymous-auth leaderboard flow
- one personal best per user + level + 2D/3D mode
- slower scores discarded
- faster scores replace the PB
- first-switch 2D/3D leaderboard invalidation warning
- switched runs are not submitted
- Try Again end-screen button
- smaller Back to main menu button
- analytics/runtime/tooling fixes
