MIST MAZE — THANKSGIVING UPDATE, DENSE LAYOUT V2

This version replaces the orderly street grid with a busy, randomized mesh of farm passages. Offset pens, bent chicken-wire walls, tight turns, barns, hay bales, crates, barrels, and carts create confusing routes with multiple ways through. Every open area stays connected. Obstacles are solid and the farmer routes around them. A new arrangement is generated each run.

INSTALL
1. Unzip this download.
2. Copy src and scripts into your existing maze-arsenal-ready project (the folder containing package.json). Merge matching folders and replace matching files. Copy README.md for updated documentation.
3. Run npm run verify, then use your normal deployment process.

This package includes all files from the Thanksgiving update, with the revised layout, so it can replace the first Thanksgiving ZIP. It is an update for the existing project, not a standalone game. No new packages or database changes are required.

The original Thanksgiving rules remain: farm lobby/store, saved hux from corn, random turkey rescues, a farmer at 1.1x normal player speed, five power-ups, and keyboard/touch controls. The event closes to new runs after November 26, 2026 in the player's local time.
