CHANGES
-------

MODE SWITCH WARNING
- The first 2D/3D switch attempt of each game shows a custom modal.
- Buttons:
    CONTINUE ANYWAY
    GO BACK
- Continue switches modes and the existing world.js leaderboard protection
  invalidates only the current run.
- Go Back stays in the current mode.
- Existing personal bests are never deleted.
- The warning resets when a new game starts or START NEW MAZE is used.
- Labyrinth mode does not show the leaderboard warning because it has no
  standard leaderboard score.

ENEMY SPEED RAMP
- Enemies can still wake/pursue normally.
- Their pursuit speed ramp stays at base speed until they have actually entered
  the player's visible field.
- 2D uses the same > 0.12 visibility threshold used to draw monsters.
- 3D requires the enemy to be inside the camera FOV and have line of sight.

LABYRINTH STEEL
Steel chance increased:
- Easy:      18% -> 24%
- Normal:    24% -> 32%
- Hard:      32% -> 42%
- Nightmare: 40% -> 52%

LABYRINTH PICKUPS
- Light pickups, Wall Breaker pickups, and any labyrinth power-up become
  anchored the first time they enter the visible field.
- Once anchored, maze shifts keep them at the same world position.
- If a shifted maze would put an anchored pickup inside a wall, a short path is
  opened so the pickup remains reachable.
- Pickups never become permanently anchored merely because they existed offscreen.

TEST
----

From the repo root:

  npm run build

Then test:
1. Start a normal level.
2. Attempt 2D -> 3D: warning should appear.
3. GO BACK: mode should not switch.
4. Attempt again in the same game: warning should not repeat.
5. START NEW MAZE: first switch should warn again.
6. Watch an enemy that wakes offscreen: speed ramp should begin only after it
   becomes visible.
7. In Labyrinth, look at a light/breaker before a shift: it should remain at
   the same position after the maze shifts.
