MIST MAZE — THEME AND BALANCE UPDATE — OCTOBER 17, 2026

INSTALL INTO YOUR EXISTING GAME
1. Unzip this download.
2. Open your game project folder containing package.json (for example total/).
3. Copy src/ into that folder, merging folders and replacing matching files.
   The main source file belongs at total/src/App.jsx, not total/src/src/App.jsx.
4. Copy the included scripts/ and root configuration files into the same project.
5. Keep the project's existing .env files, api/ folder, and supabase/ folder.
6. Run npm install, npm run verify, and npm run dev.
   Use the existing deployment process when you are ready to publish.
