MIST MAZE — LABYRINTH GAMEPLAY UPDATE

This bundle is based on the current GitHub `main` source layout.

FEATURES
-------
- Bright, pulsing START NEW GAME button centered after death/time-out.
- Existing GAME OVER / TIME EXPIRED text is left untouched.
- Labyrinth lights and Wall Breakers are distributed together across the
  full reachable maze-distance range instead of being placed as two
  separate progression groups.
- Red top-right Labyrinth timer in 2D and 3D.
- Audible once-per-second timer tick through the existing SFX engine.
- Final 30 seconds sound more urgent; final 10 seconds use a sharper double tick.
- 3D Labyrinth view shows collected lights, equipped light, and breaker charges.

INSTALL
-------
1. Make sure you are on your current `main` branch.
2. Copy:
     src/components/LabyrinthGameplayOverlay.jsx
   into your repo at the same path.
3. From the repo root run:
     git apply mist-maze-labyrinth-gameplay-update.patch
4. Run:
     npm run build
5. Test:
   - death in a normal level
   - Labyrinth in both 2D and 3D
   - SFX mute/volume
   - several new Labyrinths to inspect pickup spread
6. Commit and push main.

The patch does not delete the existing end-screen text.
