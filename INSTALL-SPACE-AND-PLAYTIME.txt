INSTALL INTO YOUR EXISTING GAME PROJECT
1. Make a backup of your existing project.
2. Extract this ZIP. Merge its src/ and scripts/ folders into the matching folders in your existing project. Replace matching files and include all new files.
3. Copy the included package.json, package-lock.json, vite.config.js, index.html, eslint.config.js, and README.md to the project root.
4. Keep your existing .env.local, api/, and supabase/ folders. They are not included in this client update. No new database setup is needed for these features.
5. From the project root, run npm install, then npm run verify. Run npm run dev to try it locally.

PATH CHECK
If your project is called total, the App file goes at total/src/App.jsx.
Do not create total/src/src/App.jsx or put the whole extracted update inside src/.
