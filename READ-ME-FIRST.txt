=======================================

This bundle contains NO .command, app, shell script, or other macOS executable.

It is based on the current GitHub `pv` branch structure.

WHAT CHANGES IN THE GAME
------------------------
- anonymous-auth global leaderboard works with the updated Supabase SQL
- one personal best is kept per player + level + mode
- faster run replaces PB; slower/equal run is discarded
- first in-game 2D <-> 3D switch shows a warning
- canceling the warning keeps the score eligible
- confirming the switch invalidates only that current run
- existing PBs are never deleted by switching modes
- Try Again appears after victory/game-over
- Back to main menu is smaller and less visually prominent
- finished runs stop continuously redrawing the canvas
- country endpoint is restored
- developer analytics writes go through the server endpoint

WHY THERE IS A VITE PLUGIN
--------------------------
Your current pv branch still has the old large src/App.jsx. Instead of asking macOS
to run an unsigned installer, this source-only bundle uses a normal Vite plugin
to apply the exact App/world/leaderboard/level-select source changes during the
Vite build. It does not execute when you double-click it in Finder, and Gatekeeper
does not need to approve it.

If the pv branch source changes enough that the exact edits no longer match,
the Vite build deliberately fails with a clear [maze-hardening] message rather
than silently deploying a partial fix.
