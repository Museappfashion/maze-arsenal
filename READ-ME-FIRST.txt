INSTALL
1. In Supabase SQL Editor, run the COMPLETE included file:
   supabase/developer-letters.sql
   It adds developer replies, preserves existing letters, and can be rerun.
   Uploading a SQL file to GitHub does not execute it in Supabase.

2. Extract this ZIP. Copy the included files into the SAME paths in your
   existing project/GitHub repository. Merge the src, api and supabase folders:
   replace matching files and add new files. Do NOT replace whole folders,
   do NOT delete your other files, and do NOT put src inside another src.
   Commit/upload all included code files together so imports are present.

3. Allow Vercel to deploy that commit, then reload the game.
   No new environment variables or dependencies are required. Keep your
   existing Supabase client/server variables and DEVELOPER_DASHBOARD_KEY.

WHAT CHANGES
- All ten purchased Myst cosmetics now combine on the in-game coin/counter.
  Existing purchases activate automatically. The shop wallet also previews
  them. Reduced-motion preferences disable the cosmetic animations.
- The developer dashboard has SEND REPLY under each received letter.
  Players open the main-menu paper/pencil button and look under YOUR INBOX.
  REFRESH loads new replies. Inbox access uses the player's saved browser
  identity; a different device/browser or cleared site data has another inbox.
- Abandoned City's 3D roads and buildings follow the actual maze and camera.
  The old fixed overlay no longer covers objects, and the city uses its own
  gray/yellow colors instead of falling back to the space theme.
- Fallen Keep arrows remain in walls for one second, then disappear.
  Bows animate their string/arrow instead of displaying a gun recoil overlay.
  Other mazes' guns and special weapons keep their existing behavior.
- Locked maze cards use crossing, interlocking white chain links.
