FULL GAME — NOVEMBER 1 UPDATE

This is the complete game with the latest updates applied.
The original game style, mazes, music, wallets, cosmetics, API configuration,
and other existing features are preserved. Old patch folders are reference
files only; no old patches need to be applied.

THE CUBE
The two-hour unlock is now one connected 3D maze: 1,000 units long,
100 units wide, and 1,000 units tall. One story is four units (250 stories).
Repeated ramps rise 1–10 stories. Walk up or down them continuously.
WASD walks, arrows move/turn, drag looks, Q hints, M opens the 3D map.
The map orbits, pans, zooms, inspects altitude slices, and shows a whole-volume
overview. Expanded map pauses movement and active playtime.
Cube saves use a separate key. Your old Hundred Floors save is preserved.

POWERUP DEFENSE
60 increasingly difficult waves; eleven powers; six upgrade tiers.
New: Scattershot, Berserk, Sonar, Bounty, Regeneration, Shield.
Controls and accurate current/next upgrade stats retain the original style.
Select powers with 1–9, 0, minus; S cycles 1x/2x/3x battle speed.

INSTALL TWO ZIP FILES
Extract CUBE-GAME-PART-1.zip and CUBE-GAME-PART-2.zip.
Move the public and PREVIEWS folders from Part 2 into Part 1, beside src
and package.json.
The combined Part 1 folder is your complete project. Use its entire contents
to replace your old code. Keep your private .env.local if you have one.

Open a terminal in that combined folder:
  npm install
  npm run dev
For the same local address as before, use:
  npm run dev -- --port 5189
Keep the same website address to retain browser-local saved progress.

Production build: npm run build
Validation: npm run verify
Regression checks: node --test scripts/tests/*.test.mjs

All public music and the production dist build are included.
node_modules, private environment files, and Git history are not distributed.
