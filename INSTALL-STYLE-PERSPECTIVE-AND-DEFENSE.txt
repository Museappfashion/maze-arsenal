INSTALL INTO YOUR EXISTING PROJECT
1. Back up your project.
2. Merge the included src/ and scripts/ into the matching folders in the project. Replace matching files and include every new file. This fix requires the renderer, engine, and style files as well as App.jsx.
3. Copy the included package.json, package-lock.json, index.html, vite.config.js, eslint.config.js, and README.md to the project root.
4. Keep your existing .env.local, api/, and supabase/ folders. No new database setup is needed for this update.
5. Run npm install, then npm run verify, then npm run dev.
