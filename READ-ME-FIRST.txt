SUPABASE — REQUIRED ONCE
------------------------
After the source files are committed/pushed, open Supabase -> SQL Editor and run:

supabase/leaderboard-top-runs-migration.sql

This migration:
- adds Level 0 to the secure leaderboard RPCs
- removes the one-PB-per-user uniqueness rule
- stores every completed valid run
- returns the top 10 per level + mode
- allows the same player to occupy multiple top-10 positions
- still returns the current user's best rank when it is outside the top 10

IMPORTANT:
Do NOT rerun the old supabase/setup.sql after this migration unless it has
first been updated to match this new top-runs design. The old setup.sql can
recreate the previous personal-best-only uniqueness rule.

Supabase Anonymous Sign-Ins must remain enabled.

FEATURES
--------
ABANDONED CITY — LEVEL 0
- New Level 0: Abandoned City
- 13x13 logical maze
- easier enemy HP/damage/speed/budget than Level 1
- default weapon names
- gray traditional urban mist/fog
- city-block/building wall treatment in 2D and 3D
- starts unlocked

LEVEL PROGRESSION
- Beat Level 0 -> unlock Level 1
- Beat Level 1 -> unlock Level 2
- Beat Level 2 -> unlock Level 3
- either 2D or 3D completion unlocks the next level for both modes
- Labyrinth is always unlocked
- unlocks persist in localStorage on the same browser/device
- locked level cards show two metal chains in an X plus a center padlock

POWER-UP HOLDER
- 3 normal slots
- Z / X / C on keyboard
- P1 / P2 / P3 on touch controls
- 3D HUD shows all three slots

LEGENDARY POWER-UPS
Exactly 2 normal power-up pickups are marked Legendary every normal run.

Legendary visual:
- gold/white aura
- gold ring
- star marker
- Legendary status retained while stored/active

Legendary effects:
- Juggernaut: max HP 220
- Wall Breaker: 12 uses, no timer
- Berserk: 2x movement speed + 2x damage
- Haste: 14x movement speed with collision-safe substeps
- Rapid Fire: existing faster fire rate; ammo consumption per second remains
  equal to normal weapon firing over the same time
- Shield: 90% damage reduction
- Regeneration: 151 actual HP healing pool; pauses while full and ends only
  after all 151 healing points have been applied
- Magnet: obtains visible pickups except weapons/guns
- Overcharge: at least 300 ammo + effectively infinite projectile travel
  until a wall stops the projectile
- Piercing Rounds: unlimited enemy piercing + 1.5x ranged damage
- Vampirism: heals 100% of actual enemy damage dealt
- Frost Field: enemy movement reduced to half base speed and disables pursuit
  acceleration/charger speed bonus while active
- Long Arms: 2x melee damage, 5x melee reach, full-circle attack
- Scattershot: each pellet/projectile receives full original shot damage
- Precision: 1.5x ranged damage, 1.5x projectile speed, exactly zero spread
- Ammo Surge: fills ammo; existing generation can overflow normal capacity;
  overflow remains until spent
- Sonar: full sight range
- Phase Walk: existing Phase Walk behavior + reflects attempted enemy damage
- Demolition: 10 wall-breaking shots, no timer
- Bounty: reward occurs on every successful hit; HP/ammo can overflow

Unless stated above, normal power-up duration/behavior is preserved.

ENEMY SPEED RAMP
- enemy must already be aggroed
- AND walking/path distance to player must be <= 30 tiles
- straight-line proximity through a wall is not enough to start the speed ramp
- existing pursuit maximum multiplier is retained
- when an enemy successfully hits the player, its pursuit ramp resets to base
- it can ramp again afterward when conditions are satisfied

ROBBIE
Case-insensitive: Robbie / robbie / ROBBIE
- starts with 200 ammo and the DMR Robbienator
- DMR is the smiley banana Robbienator
- machete becomes a smiley Plunger
- every other normal weapon gets its own Robbie color skin + smiley face
- weapon combat stats stay normal
- Robbie runs remain leaderboard-ineligible

ASHER
Case-insensitive: Asher / asher / ASHER
- Sword Gun is automatically owned
- select with key 0
- damage 45
- cooldown 0.55 sec
- ammo cost 1
- projectile speed 14
- spread 0
- blade pierces unlimited enemies
- a wall stops the blade
- normal leaderboard eligibility remains

END SCREEN
- START NEW GAME appears only after death/time-out
- TRY AGAIN appears only after victory
- button disappears immediately when clicked
- it stays hidden during the next run
- it appears again only when the next run ends
- smaller Back to main menu remains

LEADERBOARD
- server-timed run flow is retained
- top 10 fastest valid runs per level + 2D/3D mode
- same player may occupy multiple positions
- mode-switched/Robbie runs stay ineligible

LABYRINTH / AUDIO PRESERVED
- Labyrinth always unlocked
- fairer light/Wall Breaker distribution
- visible Labyrinth pickups remain anchored during shifts
- thin red MM:SS timer
- dry tick exactly when the displayed second changes
- 3D Labyrinth status HUD
- music output remains 30% louder than original enhanced setting
