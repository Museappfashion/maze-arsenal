MIST MAZE — ALL NON-AUDIO UPDATES
==================================

This bundle contains all the non-audio feature packages discussed recently.
NO soundtrack/music files are included.

IMPORTANT
---------
These packages were created at different points while your repo was changing.
Apply them carefully on a test branch first, then run `npm run build`.

01 — CORE / LEADERBOARD / MODE SWITCH
-------------------------------------
Includes:
- Supabase anonymous-auth leaderboard flow
- one personal best per player + level + 2D/3D mode
- faster result replaces PB
- slower/equal result is discarded
- server-timed leaderboard runs
- first 2D <-> 3D switch warning
- switching invalidates ONLY the current leaderboard run
- existing PB is not deleted
- Try Again / Back to main menu end-screen work
- country endpoint / developer analytics hardening work

NOTE:
This older package uses the source-hardening Vite integration approach.
Because your repo has changed since then, treat this section as the least
reliable package. If it causes a build error, do not deploy it unchanged.

02 — LABYRINTH GAMEPLAY
-----------------------
Includes:
- bright pulsing START NEW GAME button on death/time-out
- existing GAME OVER / TIME EXPIRED text remains
- red Labyrinth timer in top-right
- timer visible in both 2D and 3D
- Labyrinth lights and Wall Breakers spread across early/middle/late maze
- Labyrinth 3D power-up HUD
- collected lights / equipped light / Wall Breaker charge display

The timer visual is included here. The audible ticking portion modifies the
existing audio/SFX engine; it is gameplay SFX rather than soundtrack music.

03 — NORMAL 3D POWER-UP HUD
---------------------------
Includes:
- Z/X stored power-up slots in normal 3D
- empty-slot display
- active power-up list
- remaining duration
- hidden in 2D
- hidden in Labyrinth to avoid duplicate HUDs

04 — ROBBIENATOR
----------------
When the player name is "robbie" (case-insensitive):
- starts with the DMR
- starts with 200 ammo
- DMR is called ROBBIENATOR
- banana cosmetic
- two dark eye dots
- curved smile
- visuals in 2D and 3D
- underlying DMR combat stats stay the same
- Robbienator runs do not submit leaderboard scores
- Labyrinth remains unchanged

RECOMMENDED ORDER
-----------------
1. Make a new test branch from your latest main.
2. Apply 02 Labyrinth Gameplay.
3. Apply 03 Normal 3D Power-Up HUD.
4. Apply 04 Robbienator.
5. Only apply 01 Core/Leaderboard if your current main still lacks those
   features, because that package is older and was the one that previously
   needed Vite-build hotfixes.
6. Run `npm run build`.
7. Test locally.
8. Push the test branch and verify its Vercel preview.
9. Merge to main only after the preview works.

NO MUSIC / SOUNDTRACK FILES ARE INCLUDED.
